Spotify

Recently played tracks, synced automatically via GitHub Actions.

Setup Instructions

  1. Go to developer.spotify.com/dashboard and create an app
  2. Set redirect URI to http://localhost:8888/callback
  3. Copy your Client ID and Client Secret
  4. Run node scripts/get-spotify-token.js locally to get a refresh token
  5. Add three GitHub secrets to your repo: SPOTIFY_CLIENT_ID, SPOTIFY_CLIENT_SECRET, SPOTIFY_REFRESH_TOKEN
  6. Go to the Actions tab in your repo and enable workflows

The action runs every hour and commits updated track data to _data/spotify.json.
